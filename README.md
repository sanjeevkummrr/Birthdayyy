# 🎂 Birthday Surprise Website

A small, interactive birthday website created as a special surprise for a good friend. ❤️

## ✨ Features

- 🎉 Birthday greeting section
- 📸 Personal photo gallery
- 💌 Personal birthday note
- 🎵 Birthday music
- ❤️ Floating hearts animation
- ✨ Smooth scroll animations
- 📱 Responsive design for mobile and desktop
- 🎨 Elegant and minimal design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages
