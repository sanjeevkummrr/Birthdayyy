BIRTHDAY WEBSITE

1. index.html, style.css and script.js same folder me rakho.
2. Images ko HTML ke img tags ke data-placeholder ke according replace karo.
   Example:
   <img src="images/memory1.jpg" data-placeholder="Memory 1">
3. Music ke liye project folder me song.mp3 rakho.
4. VS Code me index.html ko Live Server se run karo.

IMPORTANT:
- Image placeholders intentionally empty rakhe gaye hain.
- Layout mobile + desktop responsive hai.
